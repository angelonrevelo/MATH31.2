# MATH31.2

**Study guides and an answer key for MATH 31.2 (Integral Calculus). Each one is a single HTML page you open in a browser.**

These are reviewers for the course's long tests. Each topic gets the rule, the
"when to use what" reasoning, and worked examples. The equations are rendered
by MathJax. There is nothing to install or build: open a file and read it, or
print it.

Topics covered include Riemann sums, both parts of the Fundamental Theorem of
Calculus, the Mean Value Theorem for integrals, even/odd symmetry,
u-substitution, integration by parts, trig integrals and trig substitution,
partial fractions, area between curves, volumes, and arc length.

## What's here

| File | What it is |
|---|---|
| `math31.2-study_hardened.html` | The study guide, topic by topic, with patterns that show up on long tests flagged |
| `math31_2-lt.html` / `math31.2-lt.html` | Long-test reviewer: integration techniques, trig substitution table, area/volume/arc length |
| `math31.2-study.html`, `math31-study_1.html` | Earlier versions of the study guide |
| `answer_key.html` / `MATH31_2_Answer_Key.pdf` | Worked solutions with graphs. The HTML page sets letter-size margins for printing |
| `chalkboard.html` | ChalkBoard: a prototype study-platform page (subjects, notes, past-exam upload) |
| `Calculus (4).pdf` | Source reading |

## Quick start

```bash
open math31.2-study_hardened.html     # macOS; or double-click any .html file
```

You need an internet connection the first time: MathJax and the fonts load
from a CDN.

## Configuration

None. There is no `.env`.
