Module 1 — The Definite Integral
Riemann Sums & The Limit Definition
Problem ①
Show that \[\lim_{n\to\infty}\!\left(1+\frac{2}{n^2}+\frac{4}{n^2}+\frac{6}{n^2}+\cdots+\frac{2n}{n^2}\right) = \frac{1}{2}\int_1^3(1+x)\,dx.\]
This is directly from your past LT. The key skill: factor out \(\Delta x\) from each term and identify the function.
Strategy: rewrite the sum into the form \(\sum f(x_i)\,\Delta x\), then read off \(f\), \(a\), and \(b\).
Step 1
Write the sum in sigma notation. The fractional terms are \(\frac{2}{n^2}, \frac{4}{n^2}, \ldots, \frac{2n}{n^2}\), which is \(\sum_{i=1}^{n}\frac{2i}{n^2}\). Including the leading 1: \[\text{Expression} = 1 + \sum_{i=1}^{n}\frac{2i}{n^2}\] Rewrite the 1 as \(\sum_{i=1}^{n}\frac{1}{n}\) (since \(n\) copies of \(\frac{1}{n}\) sum to 1): \[= \sum_{i=1}^{n}\frac{1}{n} + \sum_{i=1}^{n}\frac{2i}{n^2} = \sum_{i=1}^{n}\!\left(\frac{1}{n}+\frac{2i}{n^2}\right) = \sum_{i=1}^{n}\frac{1}{n}\!\left(1+\frac{2i}{n}\right)\]
Step 2
Identify the Riemann sum components. We want the form \(\sum f(x_i)\,\Delta x\). Set \(\Delta x = \frac{2}{n}\), which means the interval has length \(b - a = 2\). Choose \(a = 1\), \(b = 3\). Right endpoints: \(x_i = 1 + i\cdot\frac{2}{n} = 1 + \frac{2i}{n}\). Now compare: our sum is \(\sum_{i=1}^{n}\frac{1}{n}\!\left(1+\frac{2i}{n}\right)\). Factor to show \(\Delta x\): \[\frac{1}{n} = \frac{1}{2}\cdot\frac{2}{n} = \frac{1}{2}\,\Delta x\] So the sum becomes: \[\sum_{i=1}^{n}\frac{1}{2}\,\Delta x\cdot\underbrace{\left(1+\frac{2i}{n}\right)}_{x_i} = \sum_{i=1}^{n}\frac{1}{2}(1+x_i)\,\Delta x\] This is a Riemann sum for \(f(x) = \frac{1}{2}(1+x)\).
Step 3
Take the limit: \[\lim_{n\to\infty}\sum_{i=1}^{n}\frac{1}{2}(1+x_i)\,\Delta x = \int_1^3\frac{1}{2}(1+x)\,dx = \frac{1}{2}\int_1^3(1+x)\,dx\]
Answer
The limit equals \(\dfrac{1}{2}\displaystyle\int_1^3(1+x)\,dx\) with \(f(x)=\tfrac{1+x}{2}\), \(a=1\), \(b=3\), \(\Delta x=\tfrac{2}{n}\). ✓
Problem ②
Evaluate \[\lim_{n\to\infty}\sum_{i=1}^{n}\frac{1}{n}\cdot\frac{1}{1+\!\left(\dfrac{i}{n}\right)^{\!2}}.\]
Rewrite as a Riemann sum on \([0,1]\), identify the integral, then compute it.
Strategy: match \(\Delta x\) and \(x_i\) to read off the integral directly.
Step 1
Set \(\Delta x = \frac{1}{n}\) and right endpoints \(x_i = \frac{i}{n}\) on \([0,1]\). The sum has the form \[\sum_{i=1}^{n}f(x_i)\,\Delta x \quad\text{with}\quad f(x)=\frac{1}{1+x^2}.\] As \(n\to\infty\) this is a Riemann sum for \(\displaystyle\int_0^1\frac{dx}{1+x^2}\).
Step 2
Evaluate the integral using the standard arctangent antiderivative: \[\int_0^1\frac{dx}{1+x^2} = \Big[\arctan x\Big]_0^1 = \arctan 1 - \arctan 0 = \frac{\pi}{4} - 0 = \frac{\pi}{4}.\]
Answer
\(\dfrac{\pi}{4}\) ✓
Fundamental Theorem of Calculus — Part 1
Problem ①
Find \[\frac{d}{dx}\int_{x}^{x^2}\sin(t^2)\,dt.\]
Both limits depend on \(x\). Use the Leibniz rule: \(\frac{d}{dx}\int_{g(x)}^{h(x)}f(t)\,dt = f(h(x))\,h'(x) - f(g(x))\,g'(x)\).
Strategy: apply Leibniz differentiation under the integral sign with both limits variable.
Step 1
Identify the pieces: \(f(t) = \sin(t^2)\), upper limit \(h(x)=x^2\) with \(h'(x)=2x\), lower limit \(g(x)=x\) with \(g'(x)=1\).
Step 2
Apply the Leibniz rule: \[\frac{d}{dx}\int_{x}^{x^2}\sin(t^2)\,dt = \sin\!\big((x^2)^2\big)\cdot 2x - \sin(x^2)\cdot 1 = 2x\sin(x^4) - \sin(x^2).\]
Answer
\(2x\sin(x^4) - \sin(x^2)\) ✓
Problem ②
Evaluate \[\lim_{x\to 2}\frac{1}{x-2}\int_2^x 4\ln(t^2+1)\,dt.\]
Recognize this limit as the definition of a derivative. Apply FTC1 directly.
Strategy: the limit has the form \(\lim_{x\to a}\frac{F(x)-F(a)}{x-a} = F'(a)\) where \(F(x)=\int_2^x 4\ln(t^2+1)\,dt\).
Step 1
Let \(F(x)=\displaystyle\int_2^x 4\ln(t^2+1)\,dt\). Note \(F(2)=0\), so the limit equals \(F'(2)\).
Step 2
By FTC1: \(F'(x) = 4\ln(x^2+1)\). Evaluate at \(x=2\): \[F'(2) = 4\ln(4+1) = 4\ln 5.\]
Answer
\(4\ln 5\) ✓
Problem ③
Evaluate \[\lim_{x\to 3}\frac{1}{2(x-3)}\int_5^{x^2}\ln(t-4)\,dt.\]
The upper limit is \(x^2\), so you will need the chain rule. Factor the denominator to match \(F'(3)\).
Strategy: define \(F(x)=\int_5^{x^2}\ln(t-4)\,dt\) and rewrite the limit as \(\frac{1}{2}F'(3)\).
Step 1
Note that \(F(3)=\int_5^9\ln(t-4)\,dt\) is a constant, so \[\frac{F(x)-F(3)}{2(x-3)} = \frac{1}{2}\cdot\frac{F(x)-F(3)}{x-3}\xrightarrow{x\to 3}\frac{1}{2}F'(3).\]
Step 2
Differentiate \(F\) using FTC1 and the chain rule (upper limit \(u=x^2\), \(u'=2x\)): \[F'(x) = \ln(x^2-4)\cdot 2x.\] Evaluate at \(x=3\): \[F'(3) = \ln(9-4)\cdot 6 = 6\ln 5.\]
Step 3
Combine: \[\lim_{x\to 3}\frac{1}{2(x-3)}\int_5^{x^2}\ln(t-4)\,dt = \frac{1}{2}F'(3) = \frac{1}{2}\cdot 6\ln 5 = 3\ln 5.\]
Answer
\(3\ln 5\) ✓
Problem ④
Evaluate \[\lim_{x\to 5}\frac{1}{2x-10}\int_{-x}^{x-10}\frac{t}{t^3+2}\,dt.\]
Both limits move with \(x\). Apply the Leibniz rule carefully — the lower limit is \(-x\), so its derivative is \(-1\), producing a sign flip you must track.
Strategy: let \(F(x)=\int_{-x}^{x-10}\frac{t}{t^3+2}\,dt\). Rewrite the limit as \(\frac{1}{2}F'(5)\), then differentiate \(F\) using the Leibniz rule.
Step 1
At \(x=5\): both limits equal \(-5\), so \(F(5)=0\) and \(2x-10=0\). This is a \(\frac{0}{0}\) form. Rewrite: \[\frac{F(x)}{2x-10} = \frac{F(x)-F(5)}{2(x-5)} = \frac{1}{2}\cdot\frac{F(x)-F(5)}{x-5}\to\frac{1}{2}F'(5).\]
Step 2
Set \(f(t)=\frac{t}{t^3+2}\). Upper limit \(h(x)=x-10\), \(h'(x)=1\). Lower limit \(g(x)=-x\), \(g'(x)=-1\). Leibniz rule: \[F'(x) = f(x-10)\cdot 1 - f(-x)\cdot(-1) = f(x-10) + f(-x).\] Note: the lower-limit term gets a double negative — do not drop it.
Step 3
Evaluate at \(x=5\). Both arguments equal \(-5\): \[f(-5) = \frac{-5}{(-5)^3+2} = \frac{-5}{-123} = \frac{5}{123}.\] \[F'(5) = f(-5) + f(-5) = \frac{5}{123}+\frac{5}{123} = \frac{10}{123}.\]
Answer
\(\dfrac{1}{2}\cdot\dfrac{10}{123} = \dfrac{5}{123}\) ✓
Fundamental Theorem of Calculus — Part 2
Problem ①
Evaluate \[\int_1^4 \frac{dy}{\sqrt{8y-16}}.\]
Factor inside the radical first. Then check whether the integrand is defined over the entire interval before applying FTC2.
Strategy: simplify the integrand, then check the domain carefully.
Step 1
Factor: \(8y-16 = 8(y-2)\). The integrand becomes \[\frac{1}{\sqrt{8(y-2)}} = \frac{1}{2\sqrt{2}\,\sqrt{y-2}}.\] For this to be real, we need \(y-2 > 0\), i.e.\ \(y > 2\).
⚠ Warning
⚠ Singularity inside the interval
The integrand requires \(y > 2\). Since \(y = 2\) lies inside \([1,4]\), the integrand is not defined for \(y \in [1,2)\) (the radicand is negative there) and blows up as \(y \to 2^+\).

As a result, \(\displaystyle\int_1^4 \frac{dy}{\sqrt{8y-16}}\) does not exist as a standard definite integral — the integrand is not real-valued on part of the domain. This problem is ill-posed as written.

For reference: if the lower limit were \(2\) instead of \(1\), the improper integral \(\displaystyle\int_2^4 \frac{dy}{\sqrt{8(y-2)}}\) would converge: \[\int_2^4 \frac{dy}{2\sqrt{2}\,\sqrt{y-2}} = \frac{1}{2\sqrt{2}}\cdot\Big[2\sqrt{y-2}\Big]_2^4 = \frac{1}{2\sqrt{2}}\cdot 2\sqrt{2} = 1.\]
Answer
The integral over \([1,4]\) is undefined (the integrand is not real on \([1,2)\)).
Properties of Definite Integrals
Problem ①
Show that \[\frac{1}{6e}\;\le\;\int_0^1\frac{xe^x}{1+2e^x}\,dx\;\le\;\frac{1}{2}.\]
Use the Comparison Property: if \(m \le f(x) \le M\) on \([a,b]\), then \(m(b-a)\le\int_a^b f\,dx\le M(b-a)\). Find constants \(m\) and \(M\) by bounding the integrand directly.
Strategy: bound the integrand \(f(x)=\dfrac{xe^x}{1+2e^x}\) between two constants, then apply the Comparison Property \(m(b-a)\le\int_a^b f\,dx\le M(b-a)\).
Upper Bound
Since \(1+2e^x \ge 2e^x\) (because \(1\ge 0\)): \[\frac{xe^x}{1+2e^x} \le \frac{xe^x}{2e^x} = \frac{x}{2}.\] On \([0,1]\): \(\frac{x}{2}\le\frac{1}{2}\). So \(f(x)\le\frac{1}{2}\), and therefore: \[\int_0^1 f\,dx \le \frac{1}{2}\cdot 1 = \frac{1}{2}. \quad\checkmark\]
Lower Bound
Divide numerator and denominator by \(e^x\) to rewrite: \(f(x) = \dfrac{x}{e^{-x}+2}\). On \([0,1]\): \(e^{-x}\le e^0 = 1\), so the denominator satisfies \(e^{-x}+2\le 3\). Therefore: \[\frac{x}{e^{-x}+2} \ge \frac{x}{3}.\] Integrating: \[\int_0^1 f\,dx \ge \int_0^1\frac{x}{3}\,dx = \frac{1}{3}\cdot\frac{x^2}{2}\Big|_0^1 = \frac{1}{6}.\] Since \(e>1\), we have \(\dfrac{1}{6e}<\dfrac{1}{6}\), so \(\displaystyle\int_0^1 f\,dx \ge \dfrac{1}{6} > \dfrac{1}{6e}\). \(\checkmark\)
Conclusion
\(\dfrac{1}{6e}\le\dfrac{1}{6}\le\displaystyle\int_0^1\frac{xe^x}{1+2e^x}\,dx\le\dfrac{1}{2}\) ✓
Mean Value Theorem for Integrals
Problem ①
Find all values \(c\) guaranteed by the Mean Value Theorem for Integrals for \(f(x)=x^2\) on \([1,4]\).
The MVT for integrals states: there exists \(c\in[a,b]\) with \(f(c)=\frac{1}{b-a}\int_a^b f\,dx\). Compute the average value first.
Strategy: compute the average value of \(f\), then solve \(f(c) = \text{average}\).
Step 1
Compute the average value: \[f_{\text{avg}} = \frac{1}{4-1}\int_1^4 x^2\,dx = \frac{1}{3}\cdot\frac{x^3}{3}\Big|_1^4 = \frac{1}{3}\cdot\frac{64-1}{3} = \frac{63}{9} = 7.\]
Step 2
Solve \(f(c) = 7\): \[c^2 = 7 \implies c = \sqrt{7}\quad (\text{taking the positive root since } c\in[1,4]).\]
Answer
\(c = \sqrt{7}\approx 2.646\) ✓
Problem ②
Find all values \(c\) guaranteed by the Mean Value Theorem for Integrals for \(f(x)=\sin x\) on \([0,\pi]\).
The average value of \(\sin x\) on \([0,\pi]\) is a clean number. Solve for \(c\) and note there are two solutions on \([0,\pi]\).
Strategy: compute the average, then use \(\sin c = \text{average}\).
Step 1
Compute the average value: \[f_{\text{avg}} = \frac{1}{\pi-0}\int_0^\pi\sin x\,dx = \frac{1}{\pi}\big[-\cos x\big]_0^\pi = \frac{1}{\pi}\big[1+1\big] = \frac{2}{\pi}.\]
Step 2
Solve \(\sin c = \dfrac{2}{\pi}\) on \([0,\pi]\): \[c = \arcsin\!\left(\frac{2}{\pi}\right)\quad\text{or}\quad c = \pi - \arcsin\!\left(\frac{2}{\pi}\right).\] Both values lie in \([0,\pi]\). Numerically, \(c\approx 0.690\) or \(c\approx 2.452\).
Answer
\(c = \arcsin\!\dfrac{2}{\pi}\) and \(c = \pi - \arcsin\!\dfrac{2}{\pi}\) ✓
Even and Odd Functions
Problem ①
Evaluate \[\int_{-1/\sqrt{3}}^{1/\sqrt{3}} x^2\sqrt{3-x^6}\,dx.\]
The integrand is even. Use symmetry to halve the interval, then apply the substitution \(u=x^3\), followed by a trigonometric substitution.
Strategy: symmetry + substitution \(u=x^3\) + trig sub \(u=\sqrt{3}\sin\theta\).
Step 1
Since \(f(x)=x^2\sqrt{3-x^6}\) satisfies \(f(-x)=(-x)^2\sqrt{3-(-x)^6}=f(x)\) (even), we have: \[\int_{-1/\sqrt{3}}^{1/\sqrt{3}} x^2\sqrt{3-x^6}\,dx = 2\int_0^{1/\sqrt{3}}x^2\sqrt{3-x^6}\,dx.\]
Step 2
Let \(u=x^3\), \(du=3x^2\,dx\). When \(x=0\): \(u=0\). When \(x=\frac{1}{\sqrt{3}}\): \(u=\frac{1}{(\sqrt{3})^3}=\frac{1}{3\sqrt{3}}\). \[= 2\int_0^{1/(3\sqrt{3})}\sqrt{3-u^2}\,\frac{du}{3} = \frac{2}{3}\int_0^{1/(3\sqrt{3})}\sqrt{3-u^2}\,du.\]
Step 3
Let \(u=\sqrt{3}\sin\theta\), \(du=\sqrt{3}\cos\theta\,d\theta\). When \(u=0\): \(\theta=0\). When \(u=\frac{1}{3\sqrt{3}}\): \[\sin\theta = \frac{u}{\sqrt{3}} = \frac{1/(3\sqrt{3})}{\sqrt{3}} = \frac{1}{3\sqrt{3}\cdot\sqrt{3}} = \frac{1}{3\cdot 3} = \frac{1}{9}.\] So the upper limit is \(\theta = \arcsin\!\tfrac{1}{9}\). \[\sqrt{3-u^2} = \sqrt{3-3\sin^2\theta}=\sqrt{3}\cos\theta.\] The integral becomes: \[\frac{2}{3}\int_0^{\arcsin(1/9)}\sqrt{3}\cos\theta\cdot\sqrt{3}\cos\theta\,d\theta = \frac{2}{3}\int_0^{\arcsin(1/9)}3\cos^2\theta\,d\theta = 2\int_0^{\arcsin(1/9)}\cos^2\theta\,d\theta.\]
Step 4
Use \(\cos^2\theta = \frac{1+\cos 2\theta}{2}\): \[= 2\cdot\frac{1}{2}\int_0^{\arcsin(1/9)}(1+\cos 2\theta)\,d\theta = \Big[\theta + \tfrac{1}{2}\sin 2\theta\Big]_0^{\arcsin(1/9)}.\] Apply \(\sin 2\theta = 2\sin\theta\cos\theta\) at \(\theta=\arcsin\!\tfrac{1}{9}\): \[\sin\theta = \frac{1}{9},\quad \cos\theta = \sqrt{1-\frac{1}{81}}=\frac{\sqrt{80}}{9}=\frac{4\sqrt{5}}{9}.\] \[\tfrac{1}{2}\sin 2\theta = \sin\theta\cos\theta = \frac{1}{9}\cdot\frac{4\sqrt{5}}{9} = \frac{4\sqrt{5}}{81}.\]
Answer
\(\arcsin\!\dfrac{1}{9} + \dfrac{4\sqrt{5}}{81}\) ✓
Problem ②
Evaluate \[\int_{-3}^{3}\!\left(x^5\cos x + x^2\right)dx.\]
Split the integrand into its odd and even parts, then use symmetry.
Strategy: determine the parity of each term and apply the symmetry rules for integrals over \([-a,a]\).
Step 1
Check parity of \(x^5\cos x\): replace \(x\) by \(-x\): \[(-x)^5\cos(-x) = -x^5\cos x.\] So \(x^5\cos x\) is odd. By the odd-function rule, \(\displaystyle\int_{-3}^3 x^5\cos x\,dx = 0\).
Step 2
Check parity of \(x^2\): \((-x)^2 = x^2\) — it is even. By the even-function rule: \[\int_{-3}^3 x^2\,dx = 2\int_0^3 x^2\,dx = 2\cdot\frac{x^3}{3}\Big|_0^3 = 2\cdot 9 = 18.\]
Answer
\(0 + 18 = 18\) ✓
Module 2 — Integration Techniques
u-Substitution
Problem ①
Evaluate \(\displaystyle\int\sin^3 x\cos x\,dx\).
Let \(u = \sin x\).
Sub
Let \(u=\sin x\), \(du=\cos x\,dx\): \[\int u^3\,du = \frac{u^4}{4}+C = \frac{\sin^4 x}{4}+C.\]
Answer
\(\dfrac{\sin^4 x}{4}+C\)
Problem ②
Evaluate \(\displaystyle\int_0^1 xe^{x^2}\,dx\).
Let \(u = x^2\). Don't forget to change the limits.
Sub
Let \(u=x^2\), \(du=2x\,dx\). When \(x=0\): \(u=0\); when \(x=1\): \(u=1\). \[\int_0^1 xe^{x^2}\,dx = \frac{1}{2}\int_0^1 e^u\,du = \frac{1}{2}\big[e^u\big]_0^1 = \frac{e-1}{2}.\]
Answer
\(\dfrac{e-1}{2}\)
Problem ③
Evaluate \(\displaystyle\int\frac{x^2}{\sqrt{x^3+1}}\,dx\).
Let \(u = x^3+1\).
Sub
Let \(u=x^3+1\), \(du=3x^2\,dx\): \[\int\frac{x^2}{\sqrt{u}}\cdot\frac{du}{3x^2} = \frac{1}{3}\int u^{-1/2}\,du = \frac{1}{3}\cdot 2u^{1/2}+C = \frac{2}{3}\sqrt{x^3+1}+C.\]
Answer
\(\dfrac{2}{3}\sqrt{x^3+1}+C\)
Problem ④
Evaluate \(\displaystyle\int\tan x\,dx\).
Rewrite \(\tan x = \frac{\sin x}{\cos x}\), then let \(u = \cos x\).
Sub
Let \(u=\cos x\), \(du=-\sin x\,dx\): \[\int\frac{\sin x}{\cos x}\,dx = -\int\frac{du}{u} = -\ln|u|+C = -\ln|\cos x|+C = \ln|\sec x|+C.\]
Answer
\(\ln|\sec x|+C\)
Integration by Parts
Problem ①
Evaluate \(\displaystyle\int xe^x\,dx\).
Let \(u=x\), \(dv=e^x\,dx\). The formula is \(\int u\,dv = uv - \int v\,du\).
Setup
\(u=x\), \(du=dx\), \(dv=e^x\,dx\), \(v=e^x\).
Apply
\(\displaystyle\int xe^x\,dx = xe^x - \int e^x\,dx = xe^x - e^x + C = (x-1)e^x+C.\)
Answer
\((x-1)e^x+C\)
Problem ②
Evaluate \(\displaystyle\int x^2\sin x\,dx\).
Apply IBP twice. Each application reduces the power of \(x\) by one.
Strategy: two rounds of IBP to reduce \(x^2\to x\to 1\).
Round 1
\(u=x^2\), \(du=2x\,dx\), \(dv=\sin x\,dx\), \(v=-\cos x\): \[\int x^2\sin x\,dx = -x^2\cos x + 2\int x\cos x\,dx.\]
Round 2
For \(\int x\cos x\,dx\): \(u=x\), \(du=dx\), \(dv=\cos x\,dx\), \(v=\sin x\): \[\int x\cos x\,dx = x\sin x - \int\sin x\,dx = x\sin x + \cos x.\]
Combine
\[\int x^2\sin x\,dx = -x^2\cos x + 2(x\sin x + \cos x)+C = -x^2\cos x + 2x\sin x + 2\cos x + C.\]
Answer
\(-x^2\cos x + 2x\sin x + 2\cos x + C\)
Inverse-Trig & Trigonometric Substitution
Problem ①
Evaluate \(\displaystyle\int\frac{2}{x\sqrt{x^6-4}}\,dx\).
Two substitutions: first \(u=x^3\) to clear the degree, then recognize the arcsecant form \(\int\frac{du}{u\sqrt{u^2-a^2}}=\frac{1}{a}\sec^{-1}\!\left|\frac{u}{a}\right|+C\).
Strategy: power-reducing sub \(u=x^3\) followed by the standard arcsecant formula.
Step 1
Let \(u=x^3\), \(du=3x^2\,dx\). Note \(x^6=u^2\) and \(x^3=u\), so: \[\int\frac{2}{x\sqrt{u^2-4}}\cdot\frac{du}{3x^2} = \int\frac{2}{3x^3\sqrt{u^2-4}}\,du = \int\frac{2}{3u\sqrt{u^2-4}}\,du.\]
Step 2
Apply the arcsecant formula with \(a=2\): \[\int\frac{2}{3u\sqrt{u^2-4}}\,du = \frac{2}{3}\cdot\frac{1}{2}\sec^{-1}\!\left|\frac{u}{2}\right|+C = \frac{1}{3}\sec^{-1}\!\left|\frac{x^3}{2}\right|+C.\]
Answer
\(\dfrac{1}{3}\sec^{-1}\!\left|\dfrac{x^3}{2}\right|+C\)
Problem ②
Evaluate \(\displaystyle\int\frac{dx}{x\sqrt{1-(\ln x)^2}}\).
One substitution reduces this to a standard arcsin form.
Sub
Let \(u=\ln x\), \(du=\frac{dx}{x}\): \[\int\frac{du}{\sqrt{1-u^2}} = \arcsin u + C = \arcsin(\ln x)+C.\]
Answer
\(\arcsin(\ln x)+C\)
Partial Fractions
Problem ①
Evaluate \(\displaystyle\int\frac{3x+2}{x^2-x-2}\,dx\).
Factor the denominator, then decompose into partial fractions.
Strategy: factor denominator, set up \(\frac{A}{x-2}+\frac{B}{x+1}\), solve for \(A\) and \(B\).
Step 1
Factor: \(x^2-x-2=(x-2)(x+1)\). Write: \[\frac{3x+2}{(x-2)(x+1)}=\frac{A}{x-2}+\frac{B}{x+1}\implies 3x+2=A(x+1)+B(x-2).\] \(x=2\): \(8=3A\implies A=\tfrac{8}{3}\). \quad\(x=-1\): \(-1=-3B\implies B=\tfrac{1}{3}\).
Step 2
Integrate: \[\int\!\left(\frac{8/3}{x-2}+\frac{1/3}{x+1}\right)\!dx = \frac{8}{3}\ln|x-2|+\frac{1}{3}\ln|x+1|+C.\]
Answer
\(\dfrac{8}{3}\ln|x-2|+\dfrac{1}{3}\ln|x+1|+C\)
Completing the Square
Problem ①
Evaluate \(\displaystyle\int\frac{dx}{x^2+4x+13}\).
Complete the square in the denominator to obtain the arctangent form \(\int\frac{du}{u^2+a^2}=\frac{1}{a}\arctan\frac{u}{a}+C\).
Step 1
Complete the square: \(x^2+4x+13=(x+2)^2+9\). Let \(u=x+2\), \(du=dx\): \[\int\frac{du}{u^2+9}.\]
Step 2
Apply the arctangent formula with \(a=3\): \[\int\frac{du}{u^2+9}=\frac{1}{3}\arctan\frac{u}{3}+C=\frac{1}{3}\arctan\frac{x+2}{3}+C.\]
Answer
\(\dfrac{1}{3}\arctan\dfrac{x+2}{3}+C\)
Problem ②
Evaluate \(\displaystyle\int\frac{dx}{\sqrt{-x^2+4x-3}}\).
Complete the square to rewrite the radicand as \(a^2-(x-h)^2\), then use the arcsin form.
Step 1
Complete the square: \(-x^2+4x-3=-(x^2-4x+3)=-(x^2-4x+4)+1=1-(x-2)^2\). Let \(u=x-2\): \[\int\frac{du}{\sqrt{1-u^2}}.\]
Step 2
Standard arcsin form: \[\int\frac{du}{\sqrt{1-u^2}}=\arcsin u+C=\arcsin(x-2)+C.\]
Answer
\(\arcsin(x-2)+C\)
Module 3 — Applications of Integration
Area Between Curves
Problem ①
Find the area of the region bounded by \(y=x(2-x)\) and the \(x\)-axis.
Find the roots of \(x(2-x)=0\), verify the function is non-negative on the interval, then integrate.
Setup
Roots: \(x=0\) and \(x=2\). On \([0,2]\): \(x(2-x)\ge 0\). Area: \[A = \int_0^2(2x-x^2)\,dx = \Big[x^2-\frac{x^3}{3}\Big]_0^2 = 4-\frac{8}{3} = \frac{4}{3}.\]
Answer
\(\dfrac{4}{3}\)
Volumes — Disk Method
Problem ①
Find the volume of the solid obtained by rotating the region bounded by \(y=2\sqrt{x}\), \(x=2\), and \(y=0\) about the \(x\)-axis.
Use the disk formula \(V=\pi\int_a^b[f(x)]^2\,dx\).
Integrate

Volumes — Washer Method
Problem ②
Find the volume of the solid obtained by rotating the region between \(y=x\) (outer) and \(y=x^2\) (inner) on \([0,1]\) about the \(x\)-axis.
Use the washer formula \(V=\pi\int_a^b\!\left([R(x)]^2-[r(x)]^2\right)dx\).
Verify
On \([0,1]\): \(x\ge x^2\), so \(R(x)=x\) (outer) and \(r(x)=x^2\) (inner). They intersect at \(x=0\) and \(x=1\). ✓
Integrate
\[V = \pi\int_0^1(x^2-x^4)\,dx = \pi\!\left[\frac{x^3}{3}-\frac{x^5}{5}\right]_0^1 = \pi\!\left(\frac{1}{3}-\frac{1}{5}\right) = \pi\cdot\frac{2}{15} = \frac{2\pi}{15}.\]
Answer
\(\dfrac{2\pi}{15}\)
Volumes — Shell Method
Problem ①
Find the volume of the solid obtained by rotating the region bounded by \(y=x^3\), \(x=2\), and \(y=0\) about the \(y\)-axis.
Use the shell formula \(V=2\pi\int_a^b x\,f(x)\,dx\).
Integrate
\[V = 2\pi\int_0^2 x\cdot x^3\,dx = 2\pi\int_0^2 x^4\,dx = 2\pi\cdot\frac{x^5}{5}\Big|_0^2 = 2\pi\cdot\frac{32}{5} = \frac{64\pi}{5}.\]
Answer
\(\dfrac{64\pi}{5}\)
Volumes by Cross-Sections (Slicing)
Problem ①
The base of a solid is a disk of radius \(R\). Cross-sections perpendicular to the \(x\)-axis are equilateral triangles. Find the volume.
At position \(x\), the chord of the disk has length \(2\sqrt{R^2-x^2}\). Use the equilateral triangle area formula \(A = \frac{\sqrt{3}}{4}s^2\).
Strategy: find \(A(x)\) using the equilateral triangle formula, then integrate from \(-R\) to \(R\).
Step 1
The base of each cross-sectional triangle equals the chord: \(s=2\sqrt{R^2-x^2}\). For an equilateral triangle with side \(s\): \[A(x) = \frac{\sqrt{3}}{4}s^2 = \frac{\sqrt{3}}{4}\cdot 4(R^2-x^2) = \sqrt{3}(R^2-x^2).\]
Step 2
Integrate using symmetry: \[V = \int_{-R}^R\sqrt{3}(R^2-x^2)\,dx = 2\sqrt{3}\int_0^R(R^2-x^2)\,dx = 2\sqrt{3}\!\left[R^2 x - \frac{x^3}{3}\right]_0^R = 2\sqrt{3}\cdot\frac{2R^3}{3} = \frac{4\sqrt{3}\,R^3}{3}.\]
Answer
\(\dfrac{4\sqrt{3}\,R^3}{3}\) ✓
Problem ②
The base of a solid is a disk of radius \(R\). Cross-sections perpendicular to the \(x\)-axis are semicircles. Find the volume.
The diameter of each semicircular cross-section equals the chord of the disk. Recall \(A = \frac{\pi r^2}{2}\).
Step 1
Chord at \(x\): \(2\sqrt{R^2-x^2}\). Diameter of semicircle = chord, so radius \(r=\sqrt{R^2-x^2}\). \[A(x) = \frac{\pi}{2}r^2 = \frac{\pi}{2}(R^2-x^2).\]
Step 2
Integrate using symmetry: \[V = \int_{-R}^R\frac{\pi}{2}(R^2-x^2)\,dx = \pi\int_0^R(R^2-x^2)\,dx = \pi\!\left[R^2 x-\frac{x^3}{3}\right]_0^R = \pi\cdot\frac{2R^3}{3} = \frac{2\pi R^3}{3}.\]
Answer
\(\dfrac{2\pi R^3}{3}\) ✓
